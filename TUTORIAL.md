# GTA-V-Data-for-Android
As GTA V is a pc game that requires high specs and storage, I have compressed all the GTA V Data into a zip file od just a few MBs. After extracting it, you can finally play the game using Gamehub or by installing the apk file.
I cannot upload the zip file as it is over 2mb, so I have instead uploaded it to gofile. The gofile link will be given below, just download it and extract it using Zarchinver. Once you have finished extracting, open the file and go to
Android version and download the apk file or use gamehub to run the exe file. The full file is only 3GB but contains everything.
